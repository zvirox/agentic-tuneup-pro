## [0.1.0-beta.1] - 2026-11-24

### Added
- **Linear Design System**: Full migration to zero-glass solid Linear-style elevated surfaces with 1px hairline borders and dual-shadow bevel illumination.
- **Real-Time Visualizations**: Integrated Apache ECharts for live memory, swap, and disk telemetry.
- **Universal TitleBar**: Integrated universal Linear TitleBar with responsive window controls.
- **Mother Ship & Starship Control Integration**: `starship-plugin` SDK integration with automatic bridge registration and discovery.
- **Native Packaging**: Unified `nfpm` generation producing Debian (`.deb`), Fedora/RHEL (`.rpm`), and Arch Linux (`.pkg.tar.zst`) packages alongside `SHA256SUMS`.
